# Flink SQL Client

Welcome! Enter 'HELP;' to list all available commands. 'QUIT;' to exit.

Command history file path: /root/.flink-sql-history

- HELP: Prints the available commands.

QUIT_EXIT: Quits the SQL client.

CLEAR: Clears the current terminal.

SET: Sets a session property. Syntax: "SET 'key'='value';". Use "SET;" for listing all properties.

RESET: Resets a session property. Syntax: "RESET 'key';". Use "RESET;" for reset all session properties.

## 第25页

要使用 Java API 开发 MCP（Model Context Protocol）服务器和客户端，可以借助 Spring Boot 和 Spring AI 提供的工具，快速构建MCP Server 和MCP Client。

Spring AI MCP地址：https://docs.spring.io/spring-ai/reference/api/mcp/mcp-overview.html

## 4.1. Java环境准备

Java API 开发MCP要求使用JDK17及以上版本、SpringBoot 3.3.x及以上版本、Maven3.6及以上版本。

这里在 Windows 中下载并安装 JDK17。使用如下链接下载 JDK 17 后进行安装，这里安装在 D 盘“D:\Program Files\Java\jdk17\jdk”中，不需要配置环境变量，只需要在相应的 SpringBoot 项目中设置使用的 JDK17 版本即可。

JDK17 下载地址：https://www.oracle.com/cn/java/technologies/downloads/#java17
